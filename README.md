# STAY IN BAR · 매출 · 급여 리포트 앱

구글폼으로 수집한 **업무일지**를 기반으로 매달 매출·급여·인센티브 리포트를 웹앱으로 보여줍니다.
사장님 페이지와 직원별 페이지가 분리되어 있고, ChatGPT API로 직원별 세부 리포트를 생성합니다.

---

## 주요 기능

### 👤 직원 페이지 (`/me`)
- 출근일수, 일한 시간
- 이번달 예상 급여, 예상 인센티브
- **실수령액** — 3.3% 원천징수 또는 4대보험 자동 계산
- 개인정보 (이름 / 전화번호 / 주민번호 / 입금계좌)
- 매장 전체 매출 열람
- AI 세부 리포트 (본인)

### 🧑‍💼 사장 페이지 (`/owner`)
- 월 총매출, 목표 달성률, 영업일수, **최종 순수익**
- 손익 계산서:
  `매출 − 총급여 − 총인센티브 − 고정비 − 부가세(10%) − 재료비/주류비(입력) − 마케팅및기타(입력) = 순수익`
- 직원별 급여·인센티브 한눈에 보기
- 직원별 상세 + AI 리포트 생성
- 엑셀/CSV 업로드 또는 구글시트 자동 연동

### 🐾 손님 도장 카드 (`/join`, QR용 · 로그인 없음)
- 손님이 QR을 찍어 **직접 등록**하고 도장을 받는 페이지(`public/join.html`)
- 보더콜리 캐릭터 **나이키**가 맞이하고, 도장이 찍히면 발도장이 팡 찍힙니다
- 재방문은 휴대폰 번호만 넣으면 도장 +1 → "웰컴 드링크는 직원에게 요청하세요"
- 5개를 다 모으면 폭죽과 함께 "엄청난 선물" 안내 → 직원에게 화면을 보여주면 됩니다
- 남용 방지: 같은 손님은 **6시간에 한 번만** 적립, 같은 IP는 10분에 40회까지
- 주소는 장부의 [백업 · 설정] 탭에서 복사할 수 있습니다 (QR 만들 때 사용)
- 테이블 비치용 인쇄물: [`print/join-qr-a5.png`](print/join-qr-a5.png) — A5(148×210mm) 300dpi,
  `https://stayinbar.vercel.app/join` QR 포함. **주소가 바뀌면 QR도 다시 만들어야 합니다.**

### 📒 고객관리 · 단골 장부 (`/customers`)
- 독립 페이지(`public/customers.html`) — **반드시 본인 이름 + 내 PIN**으로 들어옵니다
  (사장 계정은 사장 권한, 나머지는 직원 권한. 공용 PIN 방식은 없앴습니다)
- 앱에 이미 로그인한 상태라면 [고객관리]를 눌러도 **다시 로그인하지 않습니다**
- 재방문 처리 최우선: 이름·별명·뒷4자리 검색 → 한 명 남으면 Enter = 도장 +1
- 도장 5개 = 무료 1잔 보상, 누적 완주 기록
- **특성 기록**: 도장을 찍거나 새로 등록한 지 **12시간 안**인 손님에게 손님 특성을 적어둡니다.
  누가 언제 적었는지 이름·시각이 함께 남고, 지우는 건 본인이 쓴 것 또는 사장만 가능합니다.
  - 퇴근 전에 몰아서 적어도 되고, 그 자리에서 바로 적어도 됩니다
    — 신규 등록 폼의 `지금 바로 적을 특성`, 재방문 목록의 `✎ 특성 적기` 버튼
- 잘못 누른 동작은 ↩ 취소, 취소를 잘못 눌렀으면 ↪ 되살리기 — 최근 20개까지
- 이번 달 생일 / 3주 미방문 CSV (광고 수신 동의자만), 통계, JSON 백업/복원
- 직원 모드에선 전화번호 뒷4자리만 표시
- 저장소(Upstash Redis)가 연결돼 있으면 **모든 기기가 한 장부**를 씁니다

### 🔑 PIN
- 직원 각자 **[내 정보] 화면에서 자기 PIN을 직접 변경**합니다 (지금 PIN을 알아야 변경 가능, 숫자 4~12자리)
- 사장님은 [설정]에서 전 직원 PIN을 관리할 수 있습니다
- 임원 대시보드(`/exec`)는 별도 PIN을 씁니다

### ⚙️ 설정 페이지 (`/settings`, 사장 전용)
- 연봉/시급, 세금방식(3.3% vs 4대보험), 개인정보 관리
- 월 고정비, 1일 목표매출, 부가세율, 인센티브 풀 비율
- 직원 추가/삭제, PIN 관리, 구글시트 URL 등록

## 계산 로직

| 항목 | 방식 |
|---|---|
| 월 총매출 | 날짜별 최댓값 매출을 합산 (직원마다 퇴근 시점이 달라 그날 최종 매출을 사용) |
| 기여점수 | 텍스트 컬럼의 `+N점` 패턴 합산 |
| 목표매출 | 영업일수 × 1일 목표(기본 150만원) |
| 3% 인센티브 풀 | 매출의 3% → 점장(3%풀 대상)에게 지급 |
| 2% 인센티브 풀 | 매출의 2% → 전 직원 기여점수 비례 분배 |
| 급여 | 월급제=연봉/12, 시급제=시급×근무시간 |
| 실수령(3.3%) | 급여 × (1 − 3.3%) |
| 실수령(4대보험) | 국민연금·건강보험·장기요양·고용보험 + 소득세(추정) 공제 |

> 소득세는 부양가족 등 개인 조건에 따라 달라져 **추정치**입니다.

## 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 환경변수 설정 (.env 파일 생성)
cp .env.example .env
#   → OPENAI_API_KEY 값 입력 (AI 리포트 사용 시)

# 3. 개발 서버 실행
npm run dev
#   → http://localhost:3000

# 배포용 빌드
npm run build && npm start
```

### 로그인 PIN

PIN은 `data/config.json`의 직원별 `pin` 값입니다. 직원은 [내 정보] 화면에서 스스로,
사장님은 [설정] 페이지에서 전체를 바꿀 수 있습니다.

⚠️ `data/config.json`에는 PIN·주민번호·계좌번호가 그대로 들어갑니다.
**저장소를 반드시 비공개로 두세요.**

## 데이터 연동

### 방법 A — 파일 업로드
구글폼 응답 시트를 `.xlsx` 또는 `.csv`로 내려받아 사장 페이지에서 업로드.
테스트용 샘플: [`samples/sample_worklog.csv`](samples/sample_worklog.csv)

### 방법 B — 구글시트 자동 연동
1. 구글시트 → 공유 → "링크가 있는 모든 사용자"(보기 권한)
2. CSV 내보내기 URL 형식:
   `https://docs.google.com/spreadsheets/d/<시트ID>/export?format=csv&gid=<gid>`
3. 설정 페이지의 "구글시트 공개 CSV URL"에 붙여넣기 → 자동으로 최신 데이터 로드

## 컬럼 매칭

시트의 "수행자 이름"이 직원 설정의 **별칭(aliases)** 과 매칭됩니다.
예: 폼에 `Joon Manager (메인바텐더,점장님)`로 제출 → 김준식의 별칭에 `Joon Manager` 등록.
매칭 안 된 이름은 사장 대시보드에 "미등록 이름"으로 표시됩니다.

## 기술 스택

- Next.js 14 (App Router) + TypeScript
- 데이터 파싱: SheetJS(xlsx)
- AI 리포트: OpenAI Chat Completions API
- 설정/데이터: `data/config.json`, `data/logs.json` (파일 기반)

> ℹ️ 파일 기반 저장이므로 **하나의 서버 인스턴스**에서 실행하는 환경(로컬 PC, VPS, 단일 서버)에 적합합니다.
> Vercel 등 서버리스에 배포하려면 설정/데이터를 외부 DB로 옮기는 작업이 필요합니다.
